# What is Google Colab?

So far, you have been writing Python code in **VS Code** on your own computer. But in the AI & ML world, most engineers use a tool called **Google Colab** (short for Google Colaboratory).

---

## 1. Why Do AI Engineers Use Colab?

| Feature | VS Code (Your Computer) | Google Colab (Cloud) |
|---|---|---|
| **Where does it run?** | On your laptop/PC | On Google's powerful servers |
| **GPU/TPU access** | Only if you bought one (expensive!) | Free GPU access for ML training |
| **Setup needed?** | Install Python, libraries manually | Everything is pre-installed |
| **Sharing** | Send files via email/GitHub | Share a link (like Google Docs) |
| **Best for** | Building apps, web projects | Data analysis, ML experiments, learning |

> **In simple words:** Colab is like Google Docs, but for Python code. You write code in your browser, it runs on Google's computers, and you can share it with anyone using a link.

---

## 2. Opening Google Colab

1. Go to [colab.research.google.com](https://colab.research.google.com)
2. Sign in with your Google account
3. Click **"New Notebook"**

That's it! You now have a Python coding environment ready — no installation needed.

---

## 3. How Colab Works — Cells

A Colab notebook is made of **cells**. There are two types:

### Code Cell — Write and Run Python Code
```python
# This is a code cell. Click the play button (▶) to run it.
print("Hello from Google Colab!")
```

### Text Cell — Write Notes and Explanations
Text cells use **Markdown** (the same formatting used in GitHub README files). You can add headings, bullet points, bold text, and more.

---

## 4. Running Your First Code in Colab

Try typing these in separate code cells and pressing **Shift + Enter** to run each one:

```python
# Cell 1: Basic math
print(2 + 3)  # Output: 5
```

```python
# Cell 2: Variables
name = "Think IT Telugu"
print(f"Welcome to {name}!")
# Output: Welcome to Think IT Telugu!
```

```python
# Cell 3: A simple loop
for i in range(1, 6):
    print(f"Step {i}")
```

> **Tip:** Press `Shift + Enter` to run the current cell and move to the next one. Press `Ctrl + Enter` to run the current cell and stay on it.

---

## 5. Installing Libraries in Colab

Most popular AI & ML libraries (NumPy, Pandas, Matplotlib, Scikit-Learn) are **already installed** in Colab. But if you need something extra:

```python
# Use ! before pip to run terminal commands in Colab
!pip install chromadb
```

---

## 6. Uploading Files to Colab

You can upload CSV files or datasets directly:

```python
from google.colab import files
uploaded = files.upload()  # A file picker will appear
```

Or connect to Google Drive:

```python
from google.colab import drive
drive.mount('/content/drive')

# Now you can read files from your Drive
# Example: open('/content/drive/My Drive/data.csv')
```

---

## 7. When to Use VS Code vs Colab

| Use Case | Best Tool |
|---|---|
| Learning Python basics | VS Code or Colab |
| Quick ML experiments | ✅ **Google Colab** |
| Training ML models (needs GPU) | ✅ **Google Colab** |
| Building web apps or APIs | ✅ **VS Code** |
| Working on a team project | Both (GitHub for code, Colab for experiments) |

---

## Summary

* **Google Colab** is a free, browser-based Python environment that runs on Google's cloud servers.
* It gives you **free GPU access** — perfect for AI & ML work.
* Code is written in **cells** — run each cell individually with `Shift + Enter`.
* Popular AI libraries are **pre-installed** — no setup headaches.
* From now on, we will use Colab for all our AI & ML experiments!
