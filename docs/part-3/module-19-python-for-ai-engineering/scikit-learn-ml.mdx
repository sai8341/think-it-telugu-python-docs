# Machine Learning Basics with Scikit-Learn

Before diving into Large Language Models (LLMs) and Deep Learning, every AI engineer understands the baseline library of classical Machine Learning: **Scikit-Learn (`sklearn`)**.

---

## 1. What is Machine Learning? (Rule-Based vs Learning)

- **Traditional Programming:** You write explicit rules (`if-else` logic) + Input Data &rarr; Output Answers.
- **Machine Learning:** You feed Input Data + Target Answers &rarr; Computer learns the mathematical patterns (Rules) automatically!

---

## 2. Supervised Learning: Features ($X$) and Target ($y$)

In **Supervised Learning**, we train a model using historical data:

- **Features ($X$):** The input factors used for prediction (e.g., house size in sq feet, number of bedrooms).
- **Target ($y$):** The actual answer we want to predict (e.g., house price in lakhs).

---

## 3. Building Your First ML Model (Linear Regression)

Let's train a model to predict house prices based on house size in square feet using `scikit-learn`:

```python
from sklearn.linear_model import LinearRegression
import numpy as np

# 1. Feature Data X (House size in sq ft) - Must be 2D array
X = np.array([[600], [800], [1000], [1200], [1500]])

# 2. Target Data y (House price in Lakhs)
y = np.array([30, 40, 50, 60, 75])

# 3. Create the Model
model = LinearRegression()

# 4. Train the Model (Learn the pattern)
model.fit(X, y)

# 5. Predict price for a new 1100 sq ft house
new_house = np.array([[1100]])
predicted_price = model.predict(new_house)

print("Predicted Price for 1100 sq ft house:", predicted_price[0], "Lakhs")
# Output: Predicted Price for 1100 sq ft house: 55.0 Lakhs
```

---

## 4. The 4 Universal Steps of Every ML Model

Whether you build simple linear regression or advanced models, the workflow remains identical:

1. **Prepare Data:** Define features `X` and target `y`.
2. **Initialize Model:** Import model class from `sklearn` (e.g., `model = LinearRegression()`).
3. **Train (`.fit()`):** Pass data to `.fit(X, y)` so the algorithm learns patterns.
4. **Predict (`.predict()`):** Pass new unseen inputs to `.predict(new_X)` to get predictions.

---

## Summary

* **Scikit-Learn (`sklearn`)** is the standard Python library for traditional Machine Learning.
* **`.fit(X, y)`** trains the model on data, and **`.predict(X_new)`** makes predictions on new inputs.
