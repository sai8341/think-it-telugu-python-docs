## Practice Exercises

1. **File Creator:**
   Write a program that asks the user for their name and favorite color, then saves it to a file called `profile.txt`.

2. **Line Counter:**
   Write a program that reads a text file and prints the total number of lines in it. Handle the case where the file does not exist.

3. **CSV Report:**
   Create a CSV file called `marks.csv` with columns: Name, Math, Science, English. Add 3 student records and then read the file to print each student's name and total marks.

4. **Log Appender:**
   Write a function `add_log(message)` that appends a timestamped log entry to `app.log`. Each entry should include the current date and time.

## Placement Q&A (Interview Prep)

<AccordionGroup>
  <Accordion title="Q1. What is the difference between read(), readline(), and readlines()?">
    `read()` returns the entire file as one string. `readline()` returns the next single line. `readlines()` returns all lines as a list. For large files, iterate line-by-line using a `for` loop for best memory efficiency.
  </Accordion>

  <Accordion title="Q2. Why should you use the 'with' statement when opening files?">
    The `with` statement automatically closes the file when the block ends, even if an error occurs. This prevents resource leaks and is the Python best practice for file I/O.
  </Accordion>

  <Accordion title="Q3. What happens if you open an existing file in 'w' mode?">
    All existing content is permanently deleted and replaced. The file starts empty. To preserve existing content, use `'a'` (append) mode instead.
  </Accordion>

  <Accordion title="Q4. What is the purpose of newline='' when writing CSV files on Windows?">
    On Windows, Python adds extra blank lines between CSV rows by default. Setting `newline=""` in the `open()` call prevents these extra blank lines.
  </Accordion>
</AccordionGroup>

## Module 15 Cheat Sheet

* **open("file.txt", "r")**: Open for reading (file must exist).
* **open("file.txt", "w")**: Open for writing (overwrites existing content).
* **open("file.txt", "a")**: Open for appending (adds to end).
* **with open(...) as f**: Auto-closes file when done (always use this).
* **f.read()**: Read entire file as string.
* **f.readline()**: Read one line at a time.
* **f.readlines()**: Read all lines into a list.
* **csv.reader(f)**: Read CSV file rows as lists.
* **csv.DictReader(f)**: Read CSV rows as dictionaries.
