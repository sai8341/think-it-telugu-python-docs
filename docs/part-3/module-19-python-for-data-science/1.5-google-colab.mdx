# Introduction to Google Colab

Before diving into Data Science, there is a powerful tool you should know about: **Google Colab** (short for Colaboratory).

Typically, we use VS Code to write Python code. However, when working on Data Science and Machine Learning, we need to inspect large datasets, plot graphs, and run code incrementally to check outputs immediately. For this specific workflow, developers use a tool called **Jupyter Notebooks**.

Google Colab is a free, cloud-based version of Jupyter Notebooks provided by Google.

---

## Why Use Google Colab?

1. **Zero Setup:** You do not need to install Python, Pandas, or any other library on your local computer. Everything is pre-installed.
2. **Free GPU & TPU Access:** Running Machine Learning models requires powerful computing resources. Google Colab provides free access to powerful hardware in the cloud.
3. **Interactive Environment:** You can run individual code blocks and see the output, dataframes, and charts instantly right below the code.
4. **Easy Sharing:** You can save your notebooks directly to Google Drive and share them with others via a link, just like Google Docs.

---

## How to Open Colab?

1. Open [colab.research.google.com](https://colab.research.google.com/) in your browser.
2. Sign in using your Google account.
3. Click on **"New Notebook"** at the bottom of the pop-up window.

That's it! Your powerful cloud environment for Data Science is ready.

---

## What are Cells?

In VS Code, we usually write code in one long file. In Google Colab, we write code in smaller, modular blocks called **Cells**.

* **Code Cell:** This is where you write Python code. Press `Shift + Enter` or click the "Play" icon to execute only the code in that cell.
* **Text Cell:** This is where you write explanations, notes, headings, or add images. It supports standard Markdown formatting.

:::info Try It Now
Open a new Colab Notebook, type `print("Hello Data Science")` in the first Code Cell, and press `Shift + Enter`. The output will appear right below the cell!
:::
