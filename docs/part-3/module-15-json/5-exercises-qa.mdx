## 1. Practice Exercises

1. **User Profile Serializer:**  
   Create a Python dictionary representing your developer profile (name, skills list, years of experience, and open to work boolean). Convert it into a formatted JSON string with an indentation of 4 and print it.

2. **Save and Load Settings File:**  
   Write a program that saves a game settings dictionary (`{"volume": 80, "resolution": "1920x1080", "fullscreen": True}`) to a file named `game_config.json`. Then write code to read it back and print the current volume level.

3. **Safe API Parser:**  
   Write a function `parse_server_response(response_str)` that safely parses a given JSON string. If the string is valid, return the parsed dictionary. If it contains syntax errors, catch `json.JSONDecodeError` and return `None` with a warning message.

4. **Nested Weather Data Extractor:**  
   Given a simulated weather JSON string `{"city": "Hyderabad", "main": {"temp": 32.5, "humidity": 65}}`, parse the string and print:  
   `"The temperature in Hyderabad is 32.5°C with 65% humidity."`

## 2. Placement Q&A (Interview Prep)

<AccordionGroup>
  <Accordion title="Q1. What is the fundamental difference between json.loads() and json.load()?">
    `json.loads()` (with an **s**) parses a JSON formatted **string** in memory. `json.load()` (without an **s**) takes an open **file object** (stream) and reads the JSON content directly from disk.
  </Accordion>

  <Accordion title="Q2. What is the difference between Serialization and Deserialization?">
    * **Serialization (Dumping):** Converting an in-memory Python object (like a dict or list) into a standardized JSON text stream or file (`json.dumps` / `json.dump`).
    * **Deserialization (Loading/Parsing):** Converting a JSON text string or file into native Python data structures (`json.loads` / `json.load`).
  </Accordion>

  <Accordion title="Q3. Why are single quotes invalid in JSON keys?">
    The official JSON specification (RFC 8259) strictly mandates that all keys and string values must be enclosed in double quotation marks (`"..."`). Single quotes are a syntax error in JSON parsers.
  </Accordion>

  <Accordion title="Q4. How does Python map null, true, and false from a JSON payload?">
    * JSON `null` maps to Python's `None`.
    * JSON `true` maps to Python's `True`.
    * JSON `false` maps to Python's `False`.
  </Accordion>
</AccordionGroup>

## 3. Module 15b Cheat Sheet

```python
import json

# String in memory -> Python dict
data = json.loads('{"title": "Python Docs", "free": true}')

# Python dict -> Formatted JSON string
json_text = json.dumps(data, indent=2)

# File on disk -> Python dict
with open("data.json", "r") as file:
    config = json.load(file)

# Python dict -> File on disk
with open("data.json", "w") as file:
    json.dump(config, file, indent=4)
```
