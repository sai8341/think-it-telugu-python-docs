# Module 6: Loops

In this module, we will learn about loops. Loops are used to run a block of code multiple times. This saves us from writing duplicate code.

---

**Problem:** You want to print your name on the screen 100 times.
* **Without Loops:** You have to write `print("Sai")` 100 times.
* **With Loops:** You can do it in just 2 lines of code.

## 6.2 The for Loop

A **for loop** is used to iterate over a sequence (like a string or a range of numbers). 

* **Automatic Variable Updates:** In a `for` loop, you do not need to manually update the loop variable (like `i += 1`). Python automatically assigns the next item in the sequence to the variable at the start of every cycle.

### Using the range() Function:
The `range(start, stop, step)` function generates a sequence of numbers. 
* **Exclusive Stop Rule:** The generated sequence stops *before* the `stop` value. The end limit is always **exclusive**. For example, `range(1, 6)` generates numbers `1, 2, 3, 4, 5` (stops before 6).

```python
# Print numbers from 1 to 5
for i in range(1, 6):
    print(f"Number is {i}")
```

### range() with a Step:
You can add a third argument to define the gap (step) between numbers.
```python
# Print even numbers from 2 to 10 (using a step of 2)
for i in range(2, 11, 2):
    print(f"Even number: {i}")
# Output: 2, 4, 6, 8, 10
```

### Looping Through a String:
```python
name = "PYTHON"
for char in name:
    print(char)
# Output: Prints P, Y, T, H, O, N on separate lines
```

## 6.3 The while Loop

A **while loop** runs as long as a specified condition remains **True**.

### Example:
```python
count = 1
while count <= 5:
    print(f"Count is {count}")
    count += 1 # Updates the count so the loop can stop eventually
```

:::danger Infinite Loop Warning
If you forget to update the loop variable (like `count += 1`), the condition remains `True` forever. This creates an **Infinite Loop** that never stops. Press `Ctrl + C` in the terminal to force-stop it.
:::

* **Common Infinite Loop Mistakes:**
  1. **Forgetting to update the variable:** Leaving out the increment step (`count += 1`) entirely.
  2. **Wrong indentation:** Placing the update step inside an `if` statement block so it only increments under specific, unmet conditions.

### When to use `for` vs. `while`:

| Feature | `for` Loop | `while` Loop |
| :--- | :--- | :--- |
| **When to use** | When you know the number of repetitions in advance. | When you repeat based on a condition (unknown number of runs). |
| **Loop Variable** | Managed and updated automatically by Python. | Must be initialized and updated manually inside the loop code. |
| **Infinite Loop Risk** | Extremely low / Safe. | High (occurs if the exit condition is never met). |
| **Common Example** | Printing numbers 1 to 10 or reading text characters. | Prompting a user to "Enter password" until it is correct. |

## 6.4 The break Statement

The `break` statement is used to stop and exit the loop immediately, even if the loop condition is still True.

```python
for i in range(1, 10):
    if i == 5:
        break # Exits the loop when i becomes 5
    print(i)
# Output: 1, 2, 3, 4
```

---

## 6.5 The continue Statement

The `continue` statement skips the rest of the code in the current iteration and jumps directly to the next cycle of the loop.

```python
for i in range(1, 6):
    if i == 3:
        continue # Skips printing 3 and moves to the next iteration
    print(i)
# Output: 1, 2, 4, 5
```

---

## 6.6 The pass Statement

In Python, writing an empty loop or condition causes an error. We use the `pass` statement as a placeholder to do nothing and avoid errors.

```python
for i in range(1, 5):
    if i == 2:
        pass # Placeholder for future logic
    print(i)
```

## 6.7 Nested Loops

Writing a loop inside another loop is called a **Nested Loop**.

### Pattern Printing Example:
```python
# Prints a grid of stars
for i in range(1, 4):     # Outer loop (controls rows)
    for j in range(1, 4): # Inner loop (controls columns)
        print("*", end=" ")
    print() # Prints a new line after each row
```
### Output:
```text
* * * 
* * * 
* * * 
```
:::tip Think About It
Every time the outer loop runs once, the inner loop runs completely (3 times). Practicing nested loops is a great way to improve your logic skills!
:::
