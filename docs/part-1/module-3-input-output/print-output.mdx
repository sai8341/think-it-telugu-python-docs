# Controlling Terminal Output

Every interactive software application requires a mechanism to communicate state, logs, and computation results back to the user or system monitor. In Python, the standard console output engine is the `print()` built-in function.

## Printing Single and Multiple Expressions

At its simplest, `print()` evaluates the object passed to it and writes its string representation to standard output:

```python
print("Welcome to Think IT Telugu")
```

You can pass multiple comma-separated objects into a single `print()` call. Python will evaluate each expression and insert a single space between them automatically:

```python
user_name = "Sai"
account_tier = "Pro"
active_sessions = 3

print("User:", user_name, "| Tier:", account_tier, "| Sessions:", active_sessions)
# Output: User: Sai | Tier: Pro | Sessions: 3
```

## Special Escape Characters

When constructing text strings, certain character sequences triggered by a backslash (`\`) tell the console interpreter to perform structural formatting actions rather than printing literal characters:

```python
# \n inserts a newline break
print("First Line\nSecond Line")

# \t inserts a structured horizontal tab
print("ID:\t1042\nStatus:\tActive")
```

## Customizing Separators and Line Endings

By default, `print()` places a space between comma-separated items and appends a newline character (`\n`) at the end of execution. You can override these defaults explicitly using keyword parameters:

### The `sep` Parameter
Controls the exact string inserted between multiple items:

```python
# Format a date string using hyphen separators
print("2026", "07", "01", sep="-")
# Output: 2026-07-01
```

### The `end` Parameter
Controls the trailing character appended at the conclusion of the statement:

```python
# Prevent automatic line breaking
print("Processing data...", end=" ")
print("Done!")
# Output: Processing data... Done!
```
