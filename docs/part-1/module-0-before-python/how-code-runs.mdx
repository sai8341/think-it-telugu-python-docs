# How Computers Execute Code

Computers do not speak human languages. Inside their chips, they only understand electrical pulses represented as ones and zeros (`1` and `0`).

Because typing millions of ones and zeros by hand is nearly impossible, we write code in human-friendly languages like Python. We then rely on special software called **Translators** to convert our words into computer numbers.

## 2. Compilers vs. Interpreters

Translators come in two types: **Compilers** and **Interpreters**. 

Think of the difference like translating an English book into Telugu:
* A **Compiler** translates the *entire 200-page book all at once* before handing it to the reader.
* An **Interpreter** translates the book *live, sentence by sentence*, reading and speaking out loud simultaneously.

## 3. Why Python Uses an Interpreter

Because Python translates and executes code line by line, it gives two massive advantages to beginners and software builders:

* **No Waiting for Builds:** You do not need complex build steps. You simply save your script and click Run to see immediate results.
* **Pinpoint Error Reporting:** If you make a mistake on line 10, Python executes lines 1 to 9 successfully, stops exactly at line 10, and tells you the exact problem so you can fix it quickly.
