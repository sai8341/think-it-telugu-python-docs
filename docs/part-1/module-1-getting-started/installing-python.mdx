# Getting Your Computer Ready

To write and run Python code, we need to download Python onto your computer. Think of Python as a personal translator—it takes the simple English words you write and translates them into machine language that your computer can understand.

## How to Install on Windows

1. Go to the official website: [python.org/downloads](https://www.python.org/downloads/).
2. Click the big yellow button to download the latest version for Windows.
3. Open the downloaded file to start the installation.
4. **CRITICAL STEP:** At the very bottom of the first screen, you will see a small checkbox that says **"Add python.exe to PATH"**. You **MUST check this box**.


5. After checking the box, click **"Install Now"** and wait for it to finish.

<AccordionGroup>
  <Accordion title="Common Beginner Mistake: Forgetting the PATH checkbox">
    **What happens if I forget?**
    If you do not check "Add python.exe to PATH", your computer will not know where to find Python when you try to run your code later. It will give you a scary error saying "python is not recognized."
    
    **How to fix it:**
    If you forgot, just open the installer again, click **Modify**, and make sure the box is checked!
  </Accordion>
</AccordionGroup>

## How to Install on macOS (Mac)

1. Go to [python.org/downloads](https://www.python.org/downloads/) and download the macOS version.
2. Open the downloaded file.
3. Click "Continue" and follow the standard installation steps until it finishes. (Mac users do not have to worry about the PATH checkbox!)

## Did it work? Let's check!

To make sure Python is installed correctly, we will use your computer's terminal (a simple text screen).

1. **Windows:** Search for `cmd` in your Start Menu and open "Command Prompt".
2. **Mac:** Search for `Terminal` in Spotlight and open it.

Type this exact command and press **Enter**:

```bash
python --version
```

If it worked, you will see a message like `Python 3.12.3`. That means your translator is ready!
