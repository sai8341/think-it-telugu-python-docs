# Industrial Developer Workspace

Software engineers do not write code in Notepad or online sandboxes. They utilize robust Integrated Development Environments (IDEs) providing syntax highlighting, intelligent code completion, integrated terminals, and visual debugging pipelines.

Visual Studio Code (VS Code) is the industry standard across global software and machine learning teams.

## Installing Visual Studio Code

1. Navigate to [code.visualstudio.com](https://code.visualstudio.com/).
2. Download the installer matching your system architecture (Windows, macOS, or Linux).
3. Execute the setup wizard and launch Visual Studio Code.

## Installing the Official Python Extension

To unlock code intelligence and debugging tooling, you must install Microsoft's official Python extension pack:

1. Open VS Code and click the **Extensions** icon on the left navigation bar (or press `Ctrl+Shift+X` / `Cmd+Shift+X`).
2. Type **Python** in the search box.
3. Locate the official **Python** extension published by **Microsoft** and click **Install**.

## Organizing Your Workspace

In professional development, every application lives inside a dedicated project directory.

1. Create a dedicated directory on your system named `PythonAI_Workspace`.
2. Launch VS Code, click **File -> Open Folder**, navigate to `PythonAI_Workspace`, and click **Select Folder**.

:::tip Workspace Isolation
Never scatter source code files randomly across your Desktop or Downloads folder. Keeping all modules enclosed within dedicated project workspaces ensures imports, relative file paths, and environment configurations behave predictably.
:::
