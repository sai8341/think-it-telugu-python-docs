# Pattern Matching (match-case)

In Python 3.10, developers got a modern feature called **`match-case`** (known as `switch-case` in Java/C++). 

It is designed as a **cleaner, more readable replacement for long, messy `if-elif-else` chains** when you are comparing a single variable against exact matching values.

---

## 1. Why `match-case`? (Messy elif vs Clean match-case)

Imagine checking a user's role on a website:

### ❌ Messy `if-elif` Chain:
```python
role = "admin"

if role == "admin":
    print("Full Access Allowed")
elif role == "editor":
    print("Edit Access Allowed")
elif role == "viewer":
    print("Read Only Access")
else:
    print("Unknown Role")
```

### ✅ Clean `match-case` Replacement:
```python
role = "admin"

match role:
    case "admin":
        print("Full Access Allowed")
    case "editor":
        print("Edit Access Allowed")
    case "viewer":
        print("Read Only Access")
    case _:
        print("Unknown Role")  # _ is the wildcard default (like else!)
```

---

## 2. Key Features of `match-case`

1. **`case _:` (Wildcard Default)**  
   The underscore (`_`) acts as a fallback `else` block. If none of the specific cases match, `case _:` runs.

2. **`case "B" | "C":` (Multiple Matches / OR)**  
   The pipe symbol (`|`) allows matching multiple values in a single case!

```python
grade = "B"

match grade:
    case "A":
        print("Excellent performance!")
    case "B" | "C":
        print("Good job, keep it up!")  # Matches B or C
    case "F":
        print("Work hard and try again.")
    case _:
        print("Invalid grade!")
```

---

## 3. Shortcut: Inline if-else (Ternary Operator)

Sometimes you want to assign a value to a variable based on a simple check in a single line:

```python
# Syntax: <value_if_true> if <condition> else <value_if_false>
marks = 45
result = "Pass" if marks >= 35 else "Fail"

print(result)  # Output: Pass
```

---

## Simple Q&A

### Q1: What does `match-case` replace in Python?
**Answer:** It replaces long, repetitive `if-elif-elif-else` chains when comparing a single variable against exact fixed options (like menu options 1, 2, 3 or days of the week).

### Q2: What happens if I forget `case _:`?
**Answer:** If none of the specified cases match and there is no `case _:`, Python simply does nothing and moves to the next line of code without throwing an error.

## Module Summary

*   **`if` & `if-else`:** Basic decision checks. Always remember the colon (`:`) and 4-space indentation.
*   **`elif` chains:** Check multiple conditions top-to-bottom in order.
*   **`nested if-else`:** Decisions inside decisions (inner checks).
*   **`match-case`:** A clean replacement for long `elif` chains matching exact values.
