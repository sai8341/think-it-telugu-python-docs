# Relational Evaluation & Boolean Algebra

Control flow decisions in software applications rely on evaluating whether certain conditions are true or false. Comparison operators test relationships between operands, while logical operators chain multiple Boolean tests together.

## Comparison (Relational) Operators

Comparison operators evaluate expressions and return a strict Boolean value (`True` or `False`):

| Operator | Symbol | Meaning | Example (`x = 10, y = 20`) | Evaluation |
| :---: | :---: | :--- | :---: | :---: |
| **Equal to** | `==` | Tests exact equality | `x == y` | `False` |
| **Not equal** | `!=` | Tests inequality | `x != y` | `True` |
| **Greater than**| `>` | Tests if left exceeds right | `x > y` | `False` |
| **Less than** | `<` | Tests if left is smaller | `x < y` | `True` |
| **Greater or equal**| `>=`| Tests if left is greater or identical | `x >= 10` | `True` |
| **Less or equal** | `<=`| Tests if left is smaller or identical | `y <= 15` | `False` |

:::warning Assignment vs. Equality Pitfall
A classic beginner error is confusing the single equal sign (`=`, assignment) with the double equal sign (`==`, equality check).

```python
# Assignment: Stores value 5 inside variable x
x = 5

# Equality Check: Evaluates whether x equals 5 (Returns True)
is_valid = (x == 5)
```
:::

## Logical Operators

When decision trees require validating multiple conditions simultaneously, use Python's Boolean keywords (`and`, `or`, `not`):

### 1. The `and` Operator
Returns `True` **only if both** operands evaluate to `True`. If either operand is `False`, the expression returns `False`.

```python
has_license = True
has_insurance = True

can_drive = has_license and has_insurance  # True
```

### 2. The `or` Operator
Returns `True` if **at least one** operand evaluates to `True`. It only returns `False` when both conditions fail.

```python
is_admin = False
is_owner = True

can_edit = is_admin or is_owner  # True
```

### 3. The `not` Operator
Inverts the Boolean truth value of an expression (`True` becomes `False`; `False` becomes `True`).

```python
is_locked = False
print("Access Granted:", not is_locked)  # True
```

## Chaining Comparisons

Python uniquely allows chaining comparison operators naturally, just like in formal mathematical algebra:

```python
age = 25

# Check if age falls strictly between 18 and 35
valid_candidate = 18 <= age <= 35
print(f"Eligible Candidate: {valid_candidate}")  # True
```
