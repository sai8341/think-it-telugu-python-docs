# Mathematical Computation & Variable Mutation

In software engineering, data manipulation relies heavily on mathematical computations and compound updates to memory variables. Operators represent symbols that instruct the Python engine to execute specific numerical or logical operations on operands.

## Standard Arithmetic Operators

Python supports seven primary arithmetic operators for mathematical calculations:

| Operator | Symbol | Example (`a = 10, b = 3`) | Result | Description |
| :--- | :---: | :---: | :---: | :--- |
| **Addition** | `+` | `10 + 3` | `13` | Sums two operands |
| **Subtraction** | `-` | `10 - 3` | `7` | Subtracts second operand from first |
| **Multiplication**| `*` | `10 * 3` | `30` | Multiplies two operands |
| **True Division** | `/` | `10 / 3` | `3.3333...` | Always returns a decimal `float` |
| **Floor Division**| `//` | `10 // 3` | `3` | Divides and rounds down to nearest integer |
| **Modulus** | `%` | `10 % 3` | `1` | Returns the division remainder |
| **Exponentiation**| `**` | `10 ** 3` | `1000` | Raises first operand to power of second |

### Practical Example: Even vs. Odd Check
The modulus operator (`%`) is invaluable in real-world algorithms for identifying even or odd numbers, pagination indices, and periodic batch jobs:

```python
number = 14
remainder = number % 2

print(f"Dividing {number} by 2 leaves remainder: {remainder}")
# Since remainder equals 0, the number is confirmed Even.
```

## Compound Assignment Operators

Rather than writing redundant reassignment statements like `count = count + 1`, Python provides compound assignment operators that execute computation and in-place variable assignment simultaneously:

| Operator | Example | Equivalent Expansion |
| :---: | :---: | :--- |
| `+=` | `x += 5` | `x = x + 5` |
| `-=` | `x -= 2` | `x = x - 2` |
| `*=` | `x *= 3` | `x = x * 3` |
| `/=` | `x /= 2` | `x = x / 2` |
| `//=`| `x //= 4`| `x = x // 4`|
| `%=` | `x %= 3` | `x = x % 3` |

```python
score = 100
score += 25  # Increments score in-place to 125
score //= 2  # Floor divides score in-place to 62

print(f"Final Score: {score}")
```
