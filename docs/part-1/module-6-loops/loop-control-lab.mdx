# Interrupting and Modifying Iteration

In real-world data processing pipelines, loops frequently need to exit early upon discovering a target record or skip corrupted data entries without halting the entire process. Python provides dedicated control keywords for granular iteration manipulation.

## The `break` Statement

The `break` keyword immediately terminates the innermost enclosing loop, skipping any remaining cycles completely:

```python
server_ids = [101, 102, 500, 104, 105]

for sid in server_ids:
    if sid == 500:
        print(f"Critical Error: Faulty server {sid} detected! Halting loop.")
        break
    print(f"Server {sid} checked: Normal.")
```

## The `continue` Statement

The `continue` keyword terminates the **current execution cycle only** and jumps immediately back to the loop header to process the next item:

```python
data_records = [20, -5, 45, 0, 80]

for record in data_records:
    if record <= 0:
        print("Skipping corrupted or zero record...")
        continue
    print(f"Processing valid payload: {record}")
```

## The `else` Block on Loops

Python uniquely supports attaching an `else` suite directly to `for` and `while` loops. The loop's `else` block executes **only if the loop completes successfully without encountering a `break` statement**:

```python
search_target = "Admin"
user_database = ["Guest", "Analyst", "Developer"]

for user in user_database:
    if user == search_target:
        print("Target located.")
        break
else:
    print("Search exhausted: Target not present in database.")
```

## Nested Loops

When working with multi-dimensional matrices, grid layouts, or table structures, place inner loops inside outer loops:

```python
# Generate coordinate grid pairs
for x in range(1, 3):
    for y in range(1, 3):
        print(f"Grid Cell: ({x}, {y})")
```

## Hands-On Lab Exercises

Practice these scripts in your local workspace:

```python
# Exercise 1: Interactive Password Retry Engine
attempts = 0

while attempts < 3:
    password_input = input("Enter Security Token: ")
    if password_input == "SecretAI":
        print("Authentication Successful!")
        break
    attempts += 1
    print(f"Invalid Token. Attempts remaining: {3 - attempts}")
else:
    print("Security Alert: System locked due to excessive failed attempts.")
```

```python
# Exercise 2: Prime Number Filter
for candidate in range(2, 20):
    for divisor in range(2, candidate):
        if candidate % divisor == 0:
            break
    else:
        print(f"{candidate} is a Prime Number.")
```

## Module Summary

- **`for` & `range()`:** Iterate finite sequences; `range()` stop bound is always exclusive.
- **`while` Loops:** Iterate dynamically while conditions remain `True`; require manual counters.
- **`break` & `continue`:** Exit loops instantly or skip remaining cycle instructions.
