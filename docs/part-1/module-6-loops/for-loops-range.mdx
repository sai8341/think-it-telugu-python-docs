# Iterative Automation & Sequence Traversal

In software development, writing duplicate code lines to execute repetitive tasks is an anti-pattern. **Loops** automate repetitive workflows by executing an indented block of code multiple times across a structured dataset or numerical counter.

## Why Use Loops?

Imagine needing to process 10,000 customer records or print status heartbeats every second:
- **Without Loops:** You would have to manually write 10,000 individual statements.
- **With Loops:** Two lines of code can process millions of data points dynamically.

## The `for` Loop Structure

A `for` loop iterates sequentially over items inside a sequence (such as strings, ranges, lists, or dictionaries). Python automatically handles variable assignment and loop termination:

```python
# Iterate over character elements inside a string sequence
protocol = "HTTPS"

for char in protocol:
    print(f"Inspecting character: {char}")
```

Unlike manual counter loops in low-level languages, Python's `for` loop automatically assigns the next sequence item to the loop variable (`char`) at the start of every iteration cycle.

## Numerical Sequences with `range()`

To iterate over numerical counts, use the built-in `range(start, stop, step)` generator:

### The Exclusive Stop Rule
The sequence generated by `range()` includes the `start` integer but **always terminates strictly before reaching the `stop` integer**:

```python
# Generate numbers 1 through 5 (Stops before 6)
for batch_id in range(1, 6):
    print(f"Processing Batch #{batch_id}")
```

### Specifying Step Intervals
Pass a third parameter (`step`) to skip integers or reverse counting order:

```python
# Iterate through even numbers from 2 up to 10
for even_num in range(2, 11, 2):
    print(f"Even Value: {even_num}")
```

```python
# Countdown from 5 down to 1 using negative step
for countdown in range(5, 0, -1):
    print(f"Countdown: {countdown}")
```
