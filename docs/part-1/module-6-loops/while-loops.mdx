# Dynamic State-Driven Iteration

While `for` loops iterate over known, finite sequences, **`while` loops** continuously execute an indented block of code as long as a runtime boolean expression evaluates to `True`.

## Structure of a `while` Loop

A `while` loop checks its condition at the start of every iteration cycle. If `True`, the suite runs. If `False`, the loop terminates immediately:

```python
retry_count = 0
max_retries = 3

while retry_count < max_retries:
    print(f"Attempting API connection (Attempt {retry_count + 1})...")
    retry_count += 1

print("Connection pipeline concluded.")
```

## Manual Counter Updates

Unlike `for` loops that automatically update variables, **`while` loops require explicit state manipulation inside the loop suite**. Notice line 6 above (`retry_count += 1`). Without manually advancing the state toward termination, the condition never becomes `False`.

## Preventing Infinite Loops

If a `while` loop's evaluation condition never turns `False`, the application locks up in an **infinite loop**, consuming 100% CPU thread resources until killed by the operating system:

```python
# DANGER: Infinite Loop Pitfall!
# counter = 1
# while counter <= 5:
#     print("Stuck in loop forever!")
#     # Notice: counter is never incremented!
```

:::danger Breaking Out of Infinite Loops
If you accidentally execute an infinite loop in your terminal console, press **`Ctrl + C`** immediately to trigger a `KeyboardInterrupt` and kill the running process.
:::
