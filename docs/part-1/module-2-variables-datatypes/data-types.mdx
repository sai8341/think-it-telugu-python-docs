# What are Data Types?

In the previous lesson, we learned that a **variable** is a name used to store a value. 

But what *kind* of value are we storing? 

## The Concept of Data Types

In real life, we deal with different kinds of information:
- Your name is **text**.
- Your age is a **number**.
- A light switch is either **on or off**.

Computers need to know exactly what kind of information you are giving them. This is because computers treat text very differently than numbers. 

For example, you can add two numbers together (`10 + 5`), but you cannot mathematically add the words `"Hello"` and `"World"`.

The "kind" of information you store in a variable is called its **Data Type**.

## The Core Data Types in Python

For now, you only need to know three main types of data. We will explore each of these in the next few lessons:

1. **Strings (Text)**: Used for storing letters, words, and sentences. Example: `"Alice"`
2. **Numbers**: Used for math and counting. Example: `25`
3. **Booleans**: Used for true/false situations. Example: `True`

That's it! Every time you create a variable, you are storing one of these data types inside it.
