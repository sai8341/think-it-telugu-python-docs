# What is a String?

In programming, we don't call text "text" or "words"—we call it a **String**. 

A String is simply a sequence of characters (letters, numbers, or symbols) strung together. In Python, you tell the computer that something is a String by wrapping it in quotation marks.

---

## 1. Creating Strings

You can use either single quotes (`'`) or double quotes (`"`) to create a string. Both work exactly the same way in Python!

```python
name = "Rahul"
city = 'Hyderabad'

print(name)
print(city)
```

---

## 2. The Golden Rule of Strings

Without quotation marks, Python thinks you are typing a variable name or a command. With quotation marks, Python knows you are just typing raw text.

```python
# Correct! Python sees text.
fruit = "Apple"

# ERROR! Python looks for a variable called Apple and crashes.
fruit = Apple 
```

---

## 3. Multiline Strings (Triple Quotes)

Normally, a string must start and end on the same line. If you try to press Enter and write a string on multiple lines using single or double quotes, Python will crash.

If you want to write a long paragraph or message that spans across multiple lines, you must wrap it in **triple quotes** (`"""` or `'''`):

```python
address = """Flat No: 104,
Sri Sai Residency,
Hyderabad, India."""

print(address)
```

**Output:**
```
Flat No: 104,
Sri Sai Residency,
Hyderabad, India.
```

---

## 4. Finding the Length of a String

Every string has a **length** — the total number of characters inside it (including spaces and symbols).

You can find the length of any string using the `len()` command:

```python
message = "Hello"
print(len(message))   # Output: 5

city = "Hyderabad"
print(len(city))      # Output: 9

empty = ""
print(len(empty))     # Output: 0 (nothing inside!)
```

> **Why is this useful?**
> Imagine you are building a sign-up form. You want to make sure the user's password is at least 8 characters long. You can use `len()` to check!
