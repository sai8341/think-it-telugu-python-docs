## Technical Interview Preparation

### Q1: What is the exact difference between dynamic typing and static typing?
**Answer:** In statically typed languages (such as C++, Java, or Rust), variable types are locked at compile time during declaration and cannot change. In Python (dynamically typed), variables act as reference labels pointing to objects in memory. A variable name itself carries no strict type constraint and can point to an integer at line 10 and a string at line 20.

### Q2: Why does `int(49.99)` return `49` instead of rounding to `50`?
**Answer:** Python's `int()` constructor performs truncation (chopping off the fractional component entirely) rather than mathematical rounding. If standard rounding behavior is required, use the built-in `round(49.99)` function instead.

### Q3: How does Python represent null or uninitialized state?
**Answer:** Python utilizes the singleton object `None` (of type `NoneType`). It represents clean absence of value rather than an undefined pointer or zero.

## Module Summary

- **Variables:** Human-readable reference labels pointing to memory objects.
- **Naming Constraints:** Alphanumeric and underscores only; cannot start with numbers.
- **Core Primitive Types:** `int`, `float`, `bool`, `str`, and `NoneType`.
- **Runtime Inspection:** Use `type(object)` to verify classifications.
- **Type Casting:** Use `int()`, `float()`, and `str()` for explicit transformations.
