# Built-in String Methods

Python comes with helpful built-in tools called **methods** that let you clean up, inspect, or transform text quickly. You call a method by adding a dot `.` after the string variable name.

## Changing Case (`upper`, `lower`, `title`)

```python
text = "hello world"

print(text.upper())  # Output: HELLO WORLD
print(text.lower())  # Output: hello world
print(text.title())  # Output: Hello World
```

## Removing Extra Spaces (`strip`)

When users type input into a form or console, they often leave extra empty spaces at the beginning or end. Use `.strip()` to clean them off:

```python
raw_input = "   python code   "
clean_text = raw_input.strip()

print(f"'{clean_text}'")  # Output: 'python code'
```

## Finding and Replacing Text (`find`, `replace`)

- `.find(word)` tells you the starting index where a word appears. If it is not found, it returns `-1`.
- `.replace(old, new)` returns a new string where all occurrences of the old word are replaced.

```python
message = "I like Java programming."

# Find the index of "Java"
position = message.find("Java")
print(position)  # Output: 7

# Replace "Java" with "Python"
new_message = message.replace("Java", "Python")
print(new_message)  # Output: I like Python programming.
```

## Splitting and Joining (`split`, `join`)

- `.split()` breaks a string into a list of smaller words based on spaces or commas.
- `.join()` glues a list of words back together into a single string.

```python
# Splitting a sentence into separate words
sentence = "apple,banana,grape"
fruit_list = sentence.split(",")
print(fruit_list)  # Output: ['apple', 'banana', 'grape']

# Joining a list of words with a dash
joined_text = "-".join(fruit_list)
print(joined_text)  # Output: apple-banana-grape
```

## Checking String Contents (`startswith`, `endswith`, `isdigit`)

```python
filename = "report.csv"

# Check ending
if filename.endswith(".csv"):
    print("This is a CSV data file.")

# Check if text contains only numbers
phone = "9876543210"
if phone.isdigit():
    print("Valid numeric phone number.")
```

    # Wrong - string methods return a new copy, they do not change the original
    text = "hello"
    text.upper()
    print(text)  # Still outputs "hello"
    
    # Right - store the result back into the variable
    text = text.upper()
    print(text)  # Outputs "HELLO"
